# Перспективные идеи для реализации

Дата: 2026-06-04

## 1. Поддержка GitHub API Token в настройках

**Проблема:** Текущие резолверы используют `git ls-remote` без аутентификации. GitHub ограничивает анонимные запросы: 60 запросов/час для API, ~1200 запросов/час для `git ls-remote`. Этого недостаточно для пакетной обработки больших SBOM.

**Решение:** Добавить поле `github_token` в раздел настроек sbom-helper.

**Что реализовать:**
- Поле `github_token` на странице настроек
- Использовать токен в вызовах `git ls-remote` внутри резолверов
- Хранить токен в базе настроек
- Передавать токен резолверам, которым нужен доступ к GitHub

**Пример аутентифицированного вызова:**
```python
import git

def ls_remote_authenticated(url: str, token: str) -> dict:
    authenticated_url = url.replace(
        'https://',
        f'https://oauth2:{token}@'
    )
    g = git.cmd.Git()
    return g.ls_remote(authenticated_url)
```

**Выигрыш:**
- Анонимно: 60 запросов/час (API), ~1200/час (git ls-remote)
- С токеном: 5000 запросов/час (API), без ограничений (git ls-remote)
- Токен необходим для резолвера libraries.io (идея 2) и ecosyste.ms (идея 3)
