URL Validation
Validate URLs from local database
When enabled, repository URLs found in the local database are verified (HTTP HEAD + git ls-remote) before being returned. Invalid URLs are deleted and resolution continues through the resolver chain.
Validation timeout (seconds)
Timeout for each HTTP HEAD and git ls-remote check (1-60 seconds).
GitHub API Token (optional)
GitHub Personal Access Token
Used for authenticated git ls-remote and HTTP requests. Increases rate limits from 60/hr to 5000/hr for API, and removes limits for git operations.
Generate token → Settings → Developer settings → Personal access tokens → Fine-grained or classic
Status: not set
Libraries.io Resolver (optional)
Enable libraries.io resolver
When enabled, libraries.io is used as a fallback resolver when purl2repo cannot find a repository URL.
API Key
Optional API key for higher rate limits (60 req/min vs 10 req/min).
Log in to libraries.io → API Settings
Status: not set
ecosyste.ms Resolver (optional)
Enable ecosyste.ms resolver
Live query to ecosyste.ms API for repository URL lookup. Works without API key. Key is optional for higher rate limits.
API Key (optional)
Optional API key for higher rate limits.
