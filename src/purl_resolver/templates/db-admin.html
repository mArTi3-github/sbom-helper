CSV format reference

Separator: ; (semicolon)

Encoding: UTF-8 (BOM is handled automatically)

First row: column headers (required)

Columns:

ColumnRequiredFormat
purlYesPackage URL, e.g. pkg:pypi/requests
repository_urlYesSource code repository URL
repository_typeNoe.g. github, gitlab
repository_kindNoe.g. source_code
confidenceNohigh, medium, or low
evidenceNoJSON array, e.g. ["reason1", "reason2"]
warningsNoJSON array, e.g. ["warning1"]
version_referenceNoURL to version-specific reference
resolverNoDefaults to purl2repo
resolved_atNoISO-8601 timestamp

Example:

purl;repository_url;confidence
pkg:pypi/requests;https://github.com/psf/requests;high
pkg:npm/express;https://github.com/expressjs/express;medium
